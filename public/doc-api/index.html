WhatsApp Gateway API

Passerelle WhatsApp multi-utilisateurs basée sur Baileys. My Atelier appelle cette API pour connecter des comptes WhatsApp (QR code ou pairing code) et envoyer des messages (texte, lien, fichiers, images) pour chaque utilisateur.

Authentification

Deux niveaux de clés, à ne jamais exposer côté client :

CléHeaderUtilisation
ADMIN_KEYx-admin-keyCréer/gérer les utilisateurs (backend My Atelier uniquement)
apiKey (par utilisateur)x-api-keyDémarrer une session, envoyer des messages pour cet utilisateur
webhookKey (par utilisateur)x-webhook-keyEnvoyée par le gateway sur chaque appel webhook, à vérifier côté My Atelier

POST/admin/users

Crée un utilisateur et génère sa clé API + sa clé webhook.

Body
{
  "webhookUrl": "https://myatelier.com/api/whatsapp/webhook"
}
Réponse
{
  "success": true,
  "user": {
    "userId": "5e2f...",
    "apiKey": "key_9af3...",
    "webhookUrl": "https://myatelier.com/api/whatsapp/webhook",
    "webhookKey": "whk_71bd...",
    "createdAt": "2026-07-29T10:00:00.000Z"
  }
}

GET/admin/users

Liste tous les utilisateurs enregistrés sur le gateway.

POST/admin/users/:userId/regenerate-key

Invalide l'ancienne clé API de l'utilisateur et en génère une nouvelle.

PUT/admin/users/:userId/webhook

Body
{ "webhookUrl": "https://myatelier.com/nouvelle-url" }

DELETE/admin/users/:userId

Supprime l'utilisateur et son enregistrement (ne ferme pas la session WhatsApp active).

POST/session/start x-api-key

Démarre une session WhatsApp pour l'utilisateur, en mode QR ou pairing code.

Body — mode QR
{ "mode": "qr" }
Body — mode Pairing
{ "mode": "pairing", "phoneNumber": "22507xxxxxxx" }
Le QR code (en base64) et le code de pairing sont livrés en temps réel via webhook (event: qr / event: pairing_code) et via Socket.io — voir plus bas.

GET/session/status x-api-key

Réponse
{ "success": true, "status": "connected" }

Valeurs possibles : disconnected, connecting, qr_pending, connected.

POST/session/logout x-api-key

Déconnecte le compte WhatsApp et supprime les identifiants de session sur le VPS.

POST/message/send x-api-key

Envoie un message. Utiliser multipart/form-data pour les fichiers/images.

Texte ou lien — JSON
{
  "to": "22507xxxxxxx",
  "type": "text",
  "text": "Bonjour, voici votre confirmation."
}
Image ou fichier — multipart/form-data
to: 22507xxxxxxx
type: image
caption: Votre facture
media: (fichier binaire)
ChampTypeDescription
tostringNuméro international sans le +
typestringtext · link · image · file
textstringRequis pour text/link
mediafichierRequis pour image/file

GET/message/contacts x-api-key

Liste les numéros de tous les clients qui ont déjà écrit à ce compte WhatsApp.

Réponse
{
  "success": true,
  "contacts": ["2250700000001", "2250700000002"]
}

GET/message/history x-api-key

Renvoie toutes les conversations, regroupées par contact.

Réponse
{
  "success": true,
  "conversations": {
    "2250700000001": [
      {
        "id": "3EB0...",
        "from": "2250700000001@s.whatsapp.net",
        "text": "Bonjour, c'est disponible ?",
        "message": { },
        "timestamp": 1753776000
      }
    ]
  }
}

GET/message/history/:contact x-api-key

Renvoie uniquement les messages reçus d'un contact précis (numéro sans le +).

Exemple
GET /message/history/2250700000001
Réponse
{
  "success": true,
  "contact": "2250700000001",
  "messages": [ ]
}
Chaque compte connecté a son propre dossier sur le gateway (un fichier par client). Les messages sont conservés 7 jours : une purge automatique tourne chaque jour et supprime les messages plus anciens (le fichier d'un contact est effacé s'il ne reste plus rien). Pensez à synchroniser régulièrement via ces routes ou via le webhook message_received si vous voulez conserver l'historique plus longtemps côté My Atelier.

Événements Webhook

Chaque événement est envoyé en POST vers l'URL configurée, avec le header x-webhook-key à vérifier côté My Atelier avant de traiter la requête.

Format
{
  "event": "connected",
  "userId": "5e2f...",
  "data": { },
  "timestamp": 1753776000000
}
  • qr — nouveau QR code disponible
  • pairing_code — code de pairing généré
  • connected — session WhatsApp connectée
  • disconnected — session fermée
  • message_received — message entrant reçu sur le compte (inclut désormais un champ text extrait automatiquement)

Socket.io (optionnel, temps réel côté front)

Pour afficher le QR en direct dans l'interface My Atelier sans dépendre du webhook :

const socket = io("http://VOTRE_IP_VPS:3000");
socket.emit("join", userId);
socket.on("qr", ({ qr }) => afficherQr(qr));
